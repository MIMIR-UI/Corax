## Debug Files

Just the initial debugging py files. Get youreself a pi and a sx1262, configure it, slap these files on it, bam. Pretty easy and self explanatory. 

Used for testing and debugging pi and SX1262 communication, and for basic point-to-point testing / communicating

The SX1262 communicates with the pi via serial ports, so be sure to enable that in your pi-config.
